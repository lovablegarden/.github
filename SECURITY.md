# Security policy

This is the default security policy for every repository in the LovableGarden organisation.

## Reporting a vulnerability

Please don't open a public GitHub issue, discussion or pull request for a security problem.

Report it privately through GitHub: open the **Security** tab of [lovablegarden/.github](https://github.com/lovablegarden/.github/security) and choose **Report a vulnerability**. Only the maintainers see the report.

Include what you found, where (URL, endpoint or repository), how to reproduce it, and what an attacker could do with it. We aim to confirm receipt within 3 working days and to tell you what we will do within 10 working days.

Please give us a reasonable time to fix the issue before you disclose it, and don't access or change data that isn't yours while testing.

## How we handle findings

Findings, from reports and from our own scanners, are tracked privately with remediation targets by severity (known exploited: 3 days, critical: 7 days, high: 30 days). See [docs/security/cve-policy.md](docs/security/cve-policy.md).
